## PDR-010: Google Tasks Source Badge Implementation

### Status

**Proposed**

### Date

2026-08-24

### Owner

User/AI collaboration

### Category

Feature

### Feature-Area

core

### Context
**Problem/Opportunity:**
When tasks from multiple sources (Google Tasks, TickTick) appear in the consolidated view, users need to identify which source each task came from. Source badges provide visual attribution without cluttering the interface.

**Market Forces:**
- Users managing multiple task sources need clear attribution
- Badge design must scale to future sources (TickTick, etc.)
- Visual consistency with email account badges in unified inbox

### Decision
**Decision Statement:**
Display a colored pill badge labeled "Google Tasks" (or "GT" for compact view) next to each task, using Google's brand blue (#4285F4) as the badge color.

**Rationale:**
Colored pills are consistent with the email account badge pattern. Google's brand blue provides instant recognition. Compact "GT" option allows density when many tasks are displayed.

### Consequences
#### Positive
- Clear source attribution at a glance
- Consistent with existing badge patterns in email view
- Scalable to additional sources with different colors

#### Negative
- Adds visual noise to task list
- Requires badge design system for future sources

#### Risks
- Badge color conflicts with task priority indicators → use distinct position (left side) vs priority (right side)
- Accessibility concerns with color-only differentiation → include text label alongside color

### Success Metrics
| Metric | Target | Measurement Method |
|--------|--------|-------------------|
| User recognition | 90%+ | User can identify task source from badge |
| Visual clarity | No | User feedback on badge readability |

### Alternatives Considered
#### Option B: Icon-only Badge
**Description:** Small Google Tasks icon without text.
**Trade-offs:** More compact, but less accessible and recognizable.

#### Option C: Tooltip-only Attribution
**Description:** Show source on hover/tap only.
**Trade-offs:** Cleaner interface, but requires interaction to see source.
