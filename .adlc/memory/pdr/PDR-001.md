## PDR-001: Form Factor: Electron Desktop with Embedded LAN Server

### Status

**Completed**

### Date

2026-08-23

### Owner

User/AI collaboration

### Category

Scope

### Feature-Area

system

### Context
**Problem/Opportunity:**
Spec left form factor undecided between an Electron desktop app and a Dockerized web application. This choice drives packaging, notifications, filesystem access, and how the n8n sidecar ships alongside.

**Market Forces:**
- Self-hosted productivity tooling is growing; Tauri rising as a lighter alternative
- The target persona already runs Docker but expects a first-class desktop experience

### Decision
**Decision Statement:**
Build an Electron desktop app with embedded SQLite and a small HTTP server exposing the dashboard to LAN devices (phone/tablet). n8n runs as a required dockerized sidecar.

**Rationale:**
Electron matches existing team expertise (contextbridge-allowlist and ipc-handler-registration rules exist in team directives); native notifications and filesystem access come free; LAN access satisfies mobile viewing without native mobile apps.

### Consequences
#### Positive
- Native OS notifications and filesystem access
- Team Electron experience reduces ramp-up risk
- LAN access from phone/tablet without extra apps

#### Negative
- ~150MB+ RAM footprint and large installer
- Two runtimes for users (Electron + Docker sidecar)

#### Risks
- Electron security misconfiguration → enforce team IPC/contextBridge lint rules from day one
- Unauthenticated LAN exposure → mitigated: first-run pairing token + self-signed HTTPS baseline (decided 2026-08-23)

### Success Metrics
| Metric | Target | Measurement Method |
|--------|--------|-------------------|
| Dashboard reachable from LAN device | Yes | Manual test from phone browser |

### Alternatives Considered
#### Option B: Tauri shell
**Description:** Rust-based shell using system webview, ~10MB binaries.
**Trade-offs:** Much lighter, but webview inconsistency across OSes and no team experience on record.

#### Option C: Dockerized web app only
**Description:** Compose stack serving localhost/LAN.
**Trade-offs:** Perfect n8n symmetry and trivial install, but no true native push notifications and browser-tab UX.

### Constitution/Vision Alignment
| Principle | Alignment | Notes |
|-----------|-----------|-------|
| Security by Default | ⚠️ Deviation | LAN exposure must be token-paired; TLS-on-LAN considered before v1 ship |
| Human Oversight Is Mandatory | ✅ Compliant | Desktop form keeps the user as final actor for destructive actions |
