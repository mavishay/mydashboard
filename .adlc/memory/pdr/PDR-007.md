## PDR-007: Integration Phasing: Gmail First, TickTick Over Todoist

### Status

**Completed**

### Date

2026-08-23

### Owner

User/AI collaboration

### Category

Milestone

### Feature-Area

business

### Context
**Problem/Opportunity:**
Five candidate connectors (Gmail, M365 Graph, Todoist, Google Tasks, Notion) cannot all reach quality simultaneously. Connector order determines launch credibility and dogfooding depth.

**Market Forces:**
- Gmail dominates consultant personal/client inboxes; M365 dominates corporate (an out-of-scope persona per PDR-005)
- Task-manager APIs vary widely in maturity and formality

### Decision
**Decision Statement:**
Phase connectors: (1) Gmail, (2) Microsoft Graph, (3) Google Tasks, (4) TickTick. Todoist and Notion deferred beyond v1. Task-manager ordering driven by owner daily usage (Google Tasks + TickTick).

**Rationale:**
Dogfooding effect: the owner's actual stack receives the deepest testing. Gmail's API maturity de-risks the hardest module (email triage) first.

### Consequences
#### Positive
- First release nails the highest-frequency surface (email)
- Adapter architecture proven twice before community connector requests arrive
- TickTick isolated behind adapter interface given API informality

#### Negative
- Large Todoist cohort waits past v1
- Outlook-only consultants wait until phase 2

#### Risks
- Gmail restricted-scope OAuth review delays public launch → staged scope requests, testing-mode rollout
- TickTick undocumented API changes → contract tests pinned to observed behavior

### Success Metrics
| Metric | Target | Measurement Method |
|--------|--------|-------------------|
| Connector sync fidelity | Email = full triage; Tasks = complete CRUD | Per-connector test suite |

### Alternatives Considered
#### Option B: Graph first
**Description:** M365 first to dogfood a Work account.
**Trade-offs:** Dogfooding beats market stats, but persona is Gmail-heavy.

#### Option C: All connectors in parallel
**Description:** Broad but shallow launch across five APIs.
**Trade-offs:** High risk of thin quality everywhere at once.

### Constitution/Vision Alignment
| Principle | Alignment | Notes |
|-----------|-----------|-------|
| Simplicity First | ✅ Compliant | Sequential depth beats parallel breadth |
| Memory as the Harness Core | ✅ Compliant | Adapter pattern accumulates reusable integration knowledge |
